# 🌦️ Weather App

A responsive weather application that provides real-time weather information for any city using a Weather API.

## 🚀 Features

* 🔍 Search weather by city name
* 🌡️ Display current temperature
* 💧 Show humidity levels
* 💨 Display wind speed
* ☁️ Show weather conditions with icons
* 📱 Responsive design for desktop and mobile devices

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript (ES6)
* Weather API

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/mumo-droid/weather-app.git
```

2. Navigate to the project folder:

```bash
cd weather-app
```

3. Open `index.html` in your browser, or use a local development server.

## 🔑 API Key

This project requires a Weather API key.

1. Get an API key from your weather service provider.
2. Add your API key to your JavaScript file or configuration file.

**Important:** Never commit your actual API key to GitHub. Use environment variables or a configuration file that is excluded with `.gitignore` when appropriate.
